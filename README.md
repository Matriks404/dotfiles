These are my personal ""dotfiles"" that should work on **Microsoft Windows** 24H2+.

Versions of dotfiles for other operating systems:

* **Debian GNU/Linux** 11+ (bullseye), latest version of **Linux Mint** and **OpenBSD** 7.9+ - [master branch](https://github.com/Matriks404/dotfiles/tree/master) - latest commit.
* **openSUSE Tumbleweed** - [opensuse branch](https://github.com/Matriks404/dotfiles/tree/opensuse) - commit **f8b2734** as of 2025-05-16 (deprecated and not supported).

**Note:** These dotfiles are at pre-alpha preview state and things might break! Use at your own risk.

# Prerequirements

* **[Vim](https://github.com/vim/vim-win32-installer/releases)**

# Getting latest version

Run following command as a user for who you want to install dotfiles:
```bat
curl https://raw.githubusercontent.com/Matriks404/dotfiles/refs/heads/windows/_vimrc -o "%USERPROFILE%\_vimrc"
```
